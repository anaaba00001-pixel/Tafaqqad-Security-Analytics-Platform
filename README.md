# تَفَقَّدْ | Tafaqqad

**Security Analytics Platform | منصة التحليلات الأمنية**

واجهة ثنائية اللغة لفرق العمليات الأمنية، تجمع الحوادث الأمنية، تسجيلات الدخول المشبوهة، إدارة الثغرات، وتحليل رسائل التصيّد في تجربة تحقيق موحّدة.

A bilingual security analytics interface that brings security incidents, suspicious logins, vulnerability management, and phishing-email analysis into one investigation workflow.

## Highlights

- Arabic RTL and English LTR interfaces
- Linked incident investigation timeline
- Explainable suggested evidence links
- Safe phishing-message preview
- CSV templates, import preview, filtering, and export
- Printable incident investigation summaries
- Responsive dashboard and demo dataset

## Run locally

Open `dist/index.html` in a modern browser. The prototype is buildless and has no dependency installation step.
